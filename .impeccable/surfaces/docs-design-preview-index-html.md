# Surface brief: HuoCode design preview (all pages, report first)

Scope: landing, analysis progress (sync and async), report (Overview / Map / Files tabs), small-repo report, error states, no-report-yet, How it works. Visitor mode: Operate (report), Persuade (landing).
Audience and job: developers and tech leads finding the file to review first in a public Java repository.
Constraints: PRODUCT.md. Light theme, elegant and refined, feminine touch confirmed by owner.

## Direction contract

THESIS: The report is a couture atelier's pattern table, where code is measured like cloth: precise, calm, beautiful. It refuses the dark dashboard-of-cards and the cream-plus-serif editorial default.
OWN-WORLD: Undyed cotton toile ground with a faint chalk-blue drafting grid; ink in deep aubergine-black; chalk-blue 1px rules and dashed seam lines; quadrant colours as saturated silk swatches (coral hotspot, saffron complex, cornflower changes, sage calm, violet tests, hatched selvedge for unanalysed); a garnet-rose accent for actions. Lucide line icons at 1.5 stroke.
STORY: The visitor sees the verdict, understands the four swatches, pins the first file, then explores every file by folder without scrolling a long page.
FIRST VIEWPORT: Report header strip (repo, commit, up-to-date, share) over tabs Overview / Map / Files; Overview leads with score set as a tape-measure reading, the 2x2 swatch matrix beside it, Start here list below.
FORM: candidate 6 of 7 (couture atelier pattern sheet); seed:51f295c05ce0322e. Raises: 1px hairline discipline (from centre-rail setting); state by line form, dashed/doubled, not hue alone (from emission-line rail); flat colour committed at field scale (from guide map).
SIGNATURE: the tape-measure score rule, and hotspots marked with a pin head on the map and in the file tree.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
